# Multiplayer Horror Game (Browser + Mobile)

A 3D multiplayer horror game built entirely with **JavaScript** (Node.js backend + Three.js frontend).  
Players can join lobbies, chat, and play as either **survivors** or the **monster** in a dark, eerie environment.  
Runs in the browser and is mobile-friendly with virtual joystick controls.

---

## 🎮 Features

- **Dark horror atmosphere** with fog, flickering lights, and ambient sounds
- **Multiplayer** via WebSockets
- **Lobby system**: create or join rooms
- **Random monster selection** each game
- **Survivors** must complete tasks to escape
- **Monster** hunts and eliminates survivors
- **Top-down 3D perspective** using Three.js
- **Responsive controls**:
  - Desktop: WASD/Arrow keys, Space (attack), E (task)
  - Mobile: Virtual joystick + buttons
- **Basic UI** for health, objectives, and chat
- **Placeholder assets** (images, sounds) included
